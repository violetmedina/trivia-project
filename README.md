# Tic-Tac-Toe Trivia!

This fun game is based on the gameshow Hollywood Squares. The app uses React.js and an API connection to get trivia questions and answers and then displays them when a card is choosen in the game. It then determines if the answer is correct from a set of 4 multiple choice answers to mark the spot with an X for incorrect answers, or an O for the correct answer.
